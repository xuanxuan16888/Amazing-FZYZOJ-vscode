# YZOJ VSCode Extension
福州一中在线评测系统（FZYZOJ）的 VSCode 客户端扩展。

## 项目声明
本项目为福州一中学生自发开发的非官方工具，仅用于校内学习交流，与福州一中官方、OJ 运维团队无关联。请合理使用插件，遵守学校 OJ 使用规范，禁止恶意提交、滥用接口影响服务器正常运行。

## 功能
- **在线评测**：在 VSCode 中浏览题目、提交代码、查看评测结果
- **比赛系统**：查看进行中/计划中/已结束的比赛、比赛详情与排名
- **评测记录**：浏览评测列表、查看详细评测结果（各测试点得分、编译信息等）
- **讨论区**：浏览与参与题目讨论
- **用户主页**：查看用户信息、提交统计
- **题单系统**：浏览与管理题单
- **快捷操作**：一键登录、比赛文件夹创建、代码模板自动生成
- **快速编辑**：使用 `markdown+latex` 快速的编写题面、题解、讨论，并提供折叠框等特性

## 要求
- VSCode >= 1.80.0
- 需要学校 OJ 访问权限

## 使用

### 登录
`Ctrl+Shift+P` 打开命令面板，执行 `YZOJ:登录`，输入用户名和密码即可登录。

### 命令列表
| 命令 | 说明 |
| ---- | ---- |
| `YZOJ:登录` | 登录 OJ 账号 |
| `YZOJ:首页` | 打开 OJ 首页 |
| `YZOJ:显示进行中的比赛` | 查看当前正在进行的比赛 |
| `YZOJ:显示计划中的比赛` | 查看即将开始的比赛 |
| `YZOJ:显示过去的比赛` | 查看已结束的比赛 |
| `YZOJ:显示比赛详情` | 查看比赛题目列表 |
| `YZOJ:比赛结果` | 查看比赛排名与成绩 |
| `YZOJ:比赛评测状态` | 查看比赛提交状态 |
| `YZOJ:显示题目详情` | 打开题目详情页 |
| `YZOJ:显示题目列表` | 浏览全部题目 |
| `YZOJ:显示评测列表` | 查看提交评测记录 |
| `YZOJ:显示评测记录` | 查看具体评测详情 |
| `YZOJ:递交代码` | 提交代码进行评测 |
| `YZOJ:讨论区` | 打开讨论区 |
| `YZOJ:查看讨论` | 查看具体讨论内容 |
| `YZOJ:显示题单列表` | 浏览题单 |
| `YZOJ:查看题单详情` | 查看题单内题目 |
| `YZOJ:选手排名` | 查看排行榜 |
| `YZOJ:查看个人主页` | 查看用户信息 |
| `YZOJ:查看题目状态` | 查看题目的提交状态 |

### 配置
在 VSCode 设置中搜索 `yzoj` 可配置以下选项：

| 设置 | 说明 | 默认值 |
| ---- | ---- | ------ |
| `yzoj.baseUrl` | OJ 服务器地址（不含 `/OnlineJudge`） | `` |
| `yzoj.proxyServer` | 辅助服务器地址 | `http://127.0.0.1:8199` |
| `yzoj.contest.defaultCodeTemplate` | 比赛文件夹代码模板 | C++ 模板代码 |
